# 2026-09-13 · v0.2 — 음 분할 + 조율 보정 + 오선보 (골격 선율)

v0.1 의 f0 곡선 위에 "언제부터 언제까지 어느 음인가"를 얹었다. 리듬·시김새는 아직 없다.

## 1. 만든 것

| 파일 | 역할 |
|---|---|
| `app/src/audio/notes.ts` | `estimateOffsetCents` (녹음 전체의 평균율 격자 편차, 유성 프레임 센트 소수부의 원형 평균) · `segmentNotes` (노트 세그먼트) |
| `app/src/music.ts` | Hz↔midi, 음이름. CurveView 에 있던 것을 꺼냄 |
| `app/src/components/StaffView.tsx` | VexFlow 5 오선보. 노트가 바뀔 때만 렌더, 선택·재생 위치는 SVG 그룹 클래스로만 강조 |
| `app/src/components/TuningBar.tsx` | 기준 A4 · 편차 보정 체크 · 분할 감도 슬라이더 · 선택 음 정보 |
| `CurveView` | 노트 띠(보이는 것만), 띠 탭 → 음 선택, 오선보에서 고른 음이 화면 밖이면 따라감 |
| `App` | 조율·분할 설정은 `useMemo` 로 즉시 재계산 (60초 녹음 기준 수십 ms). 개발 중 `?open=파일명` 이면 `samples/` 를 바로 연다 |

곡선·오선보 어느 쪽에서 음을 탭해도 같은 음이 양쪽에 청록으로 표시되고, 그 구간이 선택되어 재생 버튼이 그 음만 들려준다.

## 2. 분할 규칙 (`notes.ts` 머리말과 동일)

1. 무성 30ms 이상 → 끊음
2. 세그먼트 중앙값에서 0.6반음(슬라이더) 넘게 벗어난 채 40ms 지속 → 벗어나기 시작한 프레임부터 새 음
3. 에너지가 직전 140ms 골보다 12dB 이상 되살아남 → 재활(再弓) 로 보고 끊음
4. 80ms 미만 조각은 같은 음 이웃에 붙이고, 아니면 버림

## 3. 실측 (hg_180_240.wav, 60초, 장구 반주, 맥 크롬)

| 설정 | 음 수 | 100ms 미만 | 같은 음이 붙어서 갈라진 쌍 |
|---|---|---|---|
| onset 8dB · min 60ms (처음 값) | 254 | 88 | 35 |
| onset 끔 · min 60ms | 225 | 62 | 14 |
| onset 8dB · min 100ms | 188 | 0 | 24 |
| **onset 12dB · min 80ms (채택)** | **206** | **38** | — |

**장구 타점이 8dB onset 에 걸려 같은 음을 쪼갰다.** 12dB 로 올렸다. 정답(사람이 들은 음 수)은 없다 — 사용자가 앱에서 구간 재생으로 몇 음 들어 보고 감도를 정하는 게 다음 일.

편차 추정은 이 녹음에서 −1c (A4=440 기준). 다만 음마다 센트가 ±30c 로 퍼져 있다 — 평균율 격자와 산조 음정이 어긋나는 것이지 추적 오류가 아니다. 프리셋(5장)이 들어오면 여기서 다시 본다.

## 4. 확인 안 한 것

- **사파리·아이패드에서 VexFlow SVG 와 오선보 스크롤** — 크로미움 패널에서만 봤다.
- 자진모리·휘모리처럼 빠른 장단에서 min 80ms 가 8분음표를 삼키지 않는지.
- 독주(장구 없음) 녹음에서 onset 12dB 가 재활을 놓치지 않는지 — `samples/` 에 독주가 없다.
